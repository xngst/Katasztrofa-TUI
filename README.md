# Katasztrófavédelem Archívum Lekérdező TUI

Egy Python-alapú interaktív terminálfelület (TUI) a BM Országos Katasztrófavédelmi Főigazgatóság weboldalának archívumaihoz.

## Funkciók

- Interaktív terminálfelület a `rich` könyvtár használatával.
- Dátum alapú keresés (`YYYY-MM-DD` formátumban).
- Strukturált, formázott táblázatos adatok a találatokhoz.
- Folyamatos lekérdezési ciklus az alkalmazás újraindítása nélkül.
